# 顺丰速运 · 收寄标准

> 来源：顺丰速运官网 https://www.sf-express.com/chn/sc/accept-query
> 采集日期：2026-10-20

## 进出口件禁止寄递物品

以下物品属于进出口件禁止寄递范围：

- 枪支弹药及管制刀具
- 易燃易爆物品（烟花、爆竹、火药、压缩气体等）
- 毒品
- 放射性与腐蚀性物品
- 生化制品及感染性物品
- 非法出版物、印刷品、音像制品等宣传品
- 货币及伪造的货币、有价证券
- 侵犯知识产权和假冒伪劣物品
- 濒危野生动物及其制品
- 间谍专用器材及非法伪造物品
- 其他

## 顺丰有权拒绝寄递的物品

以下物品顺丰有权拒绝寄递：

- 武器及其零部件、弹药
- 现金、支票、票据、有价证券、古玩、字画、艺术品
- 各类证件、重要文件、批文、合同（现金、发票、各类有价证券、重要证件、护照、私人证件、汇票等）
- 动植物及其标本、鲜活动植物（动物、植物、鲜货、海产品、河鲜）
- 贵重物品：金砖、银条、黄金白银铂金、翡翠玉石、钻石、珠宝首饰等
- 电池类：锂电池
- 粉末状物体（液体不论是否无毒无害）
- 化学制品（液体、粉末、胶体等）
- 化学药剂、化学原料
- 不明液体、不明粉末
- 生化制品、传染性、感染性物质
- 放射性物质
- 腐蚀品（硫酸、盐酸、硝酸等）
- 毒品、麻醉药品、精神药品
- 烟草及烟草制品
- 酒类：啤酒、红酒、白酒（56 度以上禁止寄递）
- 需要冷藏或冷冻的食品（生鲜类）
- 跑腿产品类：香烟、处方药、非处方药、管制药品、药品类
- 抛光粉、磁钢及磁铁、马达、再生墨盒（带磁性物品）
- 其他顺丰认为不能安全寄递的物品
